# Planning Archive

This directory holds historical planning and status documents that are no longer live execution guides.

## What belongs here

- completed or superseded sprint plans
- historical migration plans
- session summaries and implementation handoff briefs

## Archived files

- [NEXT-SPRINT-PLAN.md](./NEXT-SPRINT-PLAN.md): shipped architecture sprint for source-of-truth and input cleanup
- [RESPONSIVE-SHELL-MIGRATION.md](./RESPONSIVE-SHELL-MIGRATION.md): historical shell migration plan that led to the current React/canvas split
- [SESSION-SUMMARY.md](./SESSION-SUMMARY.md): 2026-04-20 status snapshot from before the skin and nav work
- [SONNET-HANDOFF.md](./SONNET-HANDOFF.md): implementation brief for the original Word Hunt plus Siege split
- [PLAN-explorer-mode.md](./PLAN-explorer-mode.md): detailed implementation spec behind that handoff

## Rule

Archived docs are preserved for context, not for current execution. The live sprint always lives in the highest-numbered `planning/SPRINT-###-*.md` file.
